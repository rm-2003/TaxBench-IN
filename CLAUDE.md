# Project Instructions

## CHANGELOG rules
- Never modify or rewrite existing version entries in CHANGELOG.md
- Only append new version sections at the bottom
- Each version section uses: `## vX.Y`, then the input→output mapping table and notes — no "What's new" bullet list header
- Placeholders section lists only what is still unimplemented in that version
- After every code or schema change, update the current version's entry in CHANGELOG.md to reflect what changed
- Never start a new version section unless the user explicitly instructs it
